# Changelog

All notable changes to this project are documented in this file.

## [0.2.0] - 2026-11-18

### Added
- Story-driven opening cutscene sequence covering work, crash, recovery, firing, eviction, and the casino decision.
- Expanded casino progression systems across additional town content and overlays.
- New game content and UI support for poker, roulette, and plinko lounge experiences.
- Black Market, bank, and loan-shark related progression hooks.
- New audio SFX routines supporting cutscenes and additional gameplay systems.

### Changed
- Updated project documentation to reflect current scope and controls.
- Refined UI overlays and layout structure for new gameplay modules.

### Fixed
- Improved audio effect safety and resilience to prevent SFX runtime failures from breaking gameplay.
